============================================================
HOW TO RUN bert_val.py (ALL MODES)
============================================================

Make sure you are in the directory that contains bert_val.py.
Paths below assume your outputs live under:
  /content/drive/MyDrive/src/

------------------------------------------------------------
1) instruction MODE
------------------------------------------------------------
Single sequence:
[CLS] instruction + separator + sentence [SEP]

TRAIN + EVALUATE
------------------------------------------------------------
python bert_val.py \
  --test_fold 1 --val_fold 2 \
  --epochs 3 --batch_size 8 --max_length 256 \
  --mode instruction \
  --instruction "You are an expert legal text evaluator. Label the sentence." \
  --sep "\n\n### Sentence:\n" \
  --cpu_only true

EVAL ONLY
------------------------------------------------------------
python bert_val.py \
  --test_fold 1 --val_fold 2 \
  --batch_size 8 --max_length 256 \
  --mode instruction \
  --instruction "" --sep "" \
  --eval_only true \
  --model_dir "/content/drive/MyDrive/src/modernbert-legal-instruction-test1-val2/best-model" \
  --cpu_only true

NOTES
------------------------------------------------------------
• test_fold and val_fold must be different (1–6)
• Training uses the remaining 4 folds
• Outputs are written to:
  /content/drive/MyDrive/src/modernbert-legal-<mode>-test<TEST>-val<VAL>/

• On A100 GPUs you can safely try larger batch sizes
• prov2snt / spqry2snt require provisions.json to be present
