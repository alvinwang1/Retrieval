✅ CORE PRINCIPLE: INTERPRETIVE VALUE

A sentence has value only if it contributes interpretive meaning about the phrase of interest—its scope, contours, boundaries, features, conditions, or application—beyond what already appears in the statute.

✅ DECISION WORKFLOW (APPLY IN ORDER)
STEP 1 — Immediate “No Value” Screen

Assign no value if the sentence:

• Provides only procedural/boilerplate text
• Is irrelevant to interpreting the phrase of interest

If explicit interpretation is present:

→ "potential value" (minimal interpretive relevance)

STEP 5 — Attribution Rule for Implicit Interpretation
